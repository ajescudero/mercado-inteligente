# Security and data handling

This is a local application under development, not an audited public service.
Development and start commands bind to loopback. Do not expose them to the
Internet without reviewing access control, abuse limits, dependencies, storage
and operational recovery.

Keep credentials in local environment settings, outside Git. Optional AI
suggestions are disabled by default. Do not include keys, personal lists or
provider tokens in issues, prompts, screenshots or logs.

For a suspected vulnerability, contact the repository owner through the private
channel used for access. Share a minimal reproduction without real user data;
do not publish secrets in an issue. No response-time guarantee or bug bounty is
implied.

Automated checks cover defined fixtures and contracts. They do not constitute
penetration testing, exhaustive secret detection or proof that every external
dependency is safe.
