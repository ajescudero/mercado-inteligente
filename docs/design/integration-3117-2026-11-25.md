# Design and P01 integration — 25 November 2026

A user-visible integration error exposed a mismatch between the checkout used for
the visual preview and the checkout serving the local application. The redesigned
interface and P01 existed separately. The correction combined them in the existing
application and verified the actual serving checkout.

The integration retained DM Sans, the light/dark design tokens, source attribution,
regional vocabulary and expanded reference view. Conflicts in the cart and
comparison were resolved by keeping P01 behavior with the shared visual system.

Verification covered source-date display, a regional search, quantities, online
lines, keyboard focus and narrow layouts. The working catalog and user's list
were preserved. The historical integration recorded 46 passing checks; see the
current [validation record](../validation.md) for repository preparation results.

Operational machine paths, personal shopping-list contents, raw patches and local
backups are not part of this review document. The original local records remain
preserved separately. This note describes an observed failure and its correction;
it does not claim the earlier delivery was correct.
